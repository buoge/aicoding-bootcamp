## 脚本用途：
把子目录下的 md 文件合并成一个单独的 md 文件，用以放到 notebookllm 中避免50个文件上限的限制



## 脚本功能描述：

这个脚本集成了初始化路径提示、层级深度遍历以及内容流式合并功能。
按一级子目录聚合 Markdown 内容。脚本会遍历指定的初始目录，将每个一级子目录下的所有 .md 文件合并为一个以该目录命名的 .md 文件，并存入 all-in-one 文件夹中。


* 每个子目录下的 md 文档 内容进行合并，比如：开发指南 文件夹合并目录下全部文件后 形成 开发指南.md 单个文件 
* 如果目录下有单个 md 文件则直接复制到 all-in-one 目录下
* 调用时需要用户提供脚本的执行目录
