# 合成运动零售语义包

当前会话模型按用户要求编写具体商品与人群材料，来源记录为 `codex_conversation`，不声称进行了外部 API 调用。所有企业、商品系列、客户姓名与街道门牌均为合成设定；行政名称用于经营地区示例。

- `products.jsonl`：160 个具体商品，主租户 120 款与 960 规格，辅助租户各 20 款与 160 规格。
- `families.json`：商品类型、材质、功能、合法规格轴与运动标签。
- `business.json`：品牌定位、真实地名上的虚构门店、租户差异及场景商品绑定。
- `customers.json`：购买动机原型与合成姓名词料；消费倾向属于私有生成参数。
- `geography.json`：省市区层级与虚构地址词料。
- `commerce.json`：活动主题、搭配关系、渠道策略与仿真假设。
- `language.json`：搜索与售后表达；文字不得改变事实。

`manifest.json` 由校验与冻结命令产生。语义包仅供生成工具使用；业务用户读取编译后的商品/客户属性，不能访问潜在参数或场景真值。
