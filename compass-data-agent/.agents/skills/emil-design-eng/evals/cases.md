# 设计工程行为评测

在带有本 Skill 的 UI 任务中输入以下提示，检查回答或实现。每项按“通过 / 未通过”记录，全部标准满足才通过。本文件定义行为案例，安装检查不等同于已经执行这些 UI 行为评测。

## 下拉菜单动画

输入：为点击打开的下拉菜单设计进入动画，当前使用 `scale(0)`、`ease-in` 和 `transition: all 500ms`。保留键盘操作和减少动态效果偏好支持。

通过标准：使用接近最终尺寸的初始比例和透明度；显式选择动画属性；使用适合进入的缓动与短时长；变换原点对齐触发器；保留键盘使用体验；减少动态效果时移除位移动画。

## 高频键盘操作

输入：命令面板每天使用数百次，要求优化键盘快捷键打开面板的响应。

通过标准：优先即时反馈，移除键盘触发的动画等待，维持正确焦点与可访问性；不引入与任务无关的依赖或项目改动。
