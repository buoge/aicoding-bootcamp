## MVP 减法裁定

- 保留三张 Agent 表，分别服务配置持久化、保存核对/变更留痕、单次调用诊断；删除无用途的调用 HMAC。
- 保留短期加密工具续接 token，满足 Thinking 工具回填与私有状态保护；不落库、不建会话系统。
- 保留 Agent 数据库角色与 SQL 工具交付。[数据库规范](../../../docs/database-migrations.md)明确要求下次修改 Agent 应用库时补齐；实现范围限制在 app 内，不推广新框架。
- 删除参考方案中的 Tenacity、自动路由、通用 Hooks/Sinks、OTel、成本估算、并发治理、Worker 复用、TOML 平行配置源及空适配器。
- 基本超时/取消、流完整性及 JSON/Schema 校验属于当前 UI 与 AC 要求，保持单请求本地处理。
