产品名现确定为 **Compass**（仓库名 `compass`），DataAgent 保留为既有设计与教学场景称呼。运行工程入口：[Compass](../../README.md)。

DataAgent 是《企业级Agent工程架构实战营》的跨课主示例项目，也是课程中业务需求、Agent Runtime、治理能力与 EvalOps 的统一验证载体。产品以经营问题为首页，并按业务岗位、部门管理、数据维护、Agent 维护、运行维护和审计责任组织能力。课程能力不再逐项变成菜单：只有存在独立用户目标和高频路径的能力进入一级导航，其余作为任务详情、治理契约或后续里程碑承载。界面采用暖白与墨绿的统一工作台，左侧窄图标一级栏配合可固定/临时浮动的二级栏；分析、报告空间、插件、定时任务、看板使用独立业务入口，管理与治理保留八领域二级入口。本需求目录是 Compass 产品定义、体验设计、原型与技术方案的唯一可信源。范围与阶段以 [BRIEF](BRIEF.md) 为准；原始材料见 [context](context/_INDEX.md)。

## 使用方式

直接在浏览器打开 `design/prototype/index.html`，或在本目录运行：

```bash
python3 -m http.server 8790 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8790/design/prototype/`。

原型为单一 HTML 入口，CSS 与 JavaScript 按公共组件、场景和管理模块拆分；双击打开即可运行，也可使用上述静态服务器。无 CDN、无构建步骤。所有业务数据均为合成数据，任务、权限配置、产物版本和操作结果保存在浏览器 localStorage。

本轮包含 12 类分析场景、8 个管理领域、6 个体验身份、独立导出/发布权限及设计组件预览。分析默认进入居中输入与聚合看板案例首页；二级提供新建和全部会话，单行显示标题、运行/待授权/未读状态，支持改名、软删除与撤销。标题区搜索图标打开全文搜索弹窗，支持 Cmd/Ctrl+K、↑/↓、Enter 和 Escape；列表保留主题/时间排序。每条会话以独立 taskId 保存完整历史并支持续聊。报告空间独立管理产物，插件空间包含 Skill、Prompt、Agent、模板、数据集，看板拥有独立入口。操作说明与功能路径见 [原型 README](design/prototype/README.md)，实际验证与限制见 [验证记录](test/prototype-verification.md)。技术架构与脚手架设计保留既有工程决策；2026-10-21 新增的[产品数据模型](design/data-model.md)已同步角色、会话/任务、产物、人工决定和自动化的数据语义，运行逻辑与接口实现仍待逐阶段验证。

主要入口：`#analysis`、`#chat/<taskId>`、`#reports`、`#plugins`、`#automations`、`#boards`。`#home`、`#assets`、`#tasks` 和 `#scenario/Sxx` 保持兼容，旧浏览器会话状态由原型迁移。报告、插件、看板在本轮暂共用 `assets` 模块授权；动作与数据范围继续独立检查，三模块独立授权属于后续实现。

导航展开占据布局空间；收起后 hover 一级显示浮层，键盘与触屏提供等价操作。场景中间保持完整对话，包括可展开分析摘要与工具记录、输出、行内产物、消息操作、人工授权和底部输入。六个重点任务集中在右侧临时“场景演示”面板，点击立即显示完整对话、工具记录、授权与产物；普通会话的旧状态控件保留在折叠区；≤1180 px 使用默认收起的右侧抽屉，右上按钮打开，遮罩、Escape 或关闭按钮关闭。示例授权决定只用于明确标记的本地合成演示，迁入正式产品时移除这些演示控件。

导航、会话、搜索、插件与临时演示的验收定义见 [PRD](spec/PRD.md) 的 `AC-NAV`、`AC-CHAT`、`AC-SEARCH`、`AC-17`、`AC-DEMO`，运行检查结果以验证记录为准。
