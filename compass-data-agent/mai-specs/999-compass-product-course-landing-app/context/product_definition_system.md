企业级 Data Agent 功能清单
功能模块 一般包含什么 在样本中的位置
数据连接与范围选择 连接数据库、数仓；选择可用库表；部分产品支持上传 Excel、CSV 和业务文件 基础能力，数据源范围因产品而异
业务语义与知识 指标口径、维度、表关系、字段解释、同义词、业务规则、示例查询 企业产品的重点建设部分
自然语言问数 意图理解、指标映射、多轮追问、歧义澄清、上下文连续问答 基础能力
查询生成与执行 生成 SQL，或调用语义查询接口；执行查询；显示结果与查询依据 基础能力
可视化与交互探索 自动选图、切换图表、筛选、下钻、调整维度、继续追问 常见能力
多步骤分析 拆解问题、制定计划、多次取数、检查假设、调整分析方向 产品分化明显
代码与高级统计 Python/R 执行、清洗、分群、留存、异常检测、预测、统计检验 部分产品提供
报告与分析资产 生成报告、图表、Notebook、Dashboard；保存、编辑、导出、复用 完整产品的重要组成
定时任务与主动洞察 定期刷新报表、周期性重新分析、异常触发、消息通知 扩展能力，部分仍在 Beta/Preview
团队协作 工作空间、历史分析、共享、评论、人工复核、分析师接管 企业产品常见
Agent 配置与发布 配置数据范围、规则、工具、示例、模型；调试；发布版本 建设者与管理员使用
安全与权限 用户身份、数据权限、行列限制、脱敏、执行隔离、审计 企业级重点
评测与持续改进 基准问题、结果对照、会话反馈、失败分析、上下文改进、回归评测 成熟平台的治理能力
集成与嵌入 API、MCP、Slack/Teams 等入口，将分析能力嵌入业务系统 按产品提供
