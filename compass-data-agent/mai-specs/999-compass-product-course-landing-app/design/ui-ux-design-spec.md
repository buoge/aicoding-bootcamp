# Compass 产品设计体系

[产品定义](../spec/product-definition.md) · [完整 PRD](../spec/PRD.md) · [可运行原型](prototype/index.html) · [组件预览](prototype/index.html#design)

本规范统一 Compass 的业务分析、部门管理和系统治理体验。需求依据为 Feature 999 的两份用户材料与 2026-10-20 的会话澄清。产品设计与 HTML 原型处于 `review`，工程系统仍为 M0 脚手架。

## 1. 设计方向与取舍

**安静地呈现，清楚地行动。** 用暖白画布、墨绿主色、低饱和鼠尾草色和精确数据排版建立信任。分析首页围绕问题输入；复杂性随任务逐层出现。首页叙事标题可用宋体，操作界面统一系统无衬线，数字开启等宽。

沿用原设计的绿色识别、证据邻近、状态可行动、授权范围可见等原则。本轮按用户确认的 ChatGPT 侧栏交互，采用窄图标一级栏与可固定/临时浮动的二级栏，聚合角色能力为同一 Web 的权限导航。首页原有大幅数据生命体与持续粒子动效退出高频工作界面；历史本地素材保留，可在后续产品宣传页面中评审复用。

### 设计依据

- `ui-ux-pro-max` 的 `enterprise analytics AI workspace` 查询返回 Minimalism & Swiss Style，布局与企业应用相符；其营销 Hero 模式、AI 紫粉配色和联网字体不适用于本工作台，未采用。
- 缩小到 `business intelligence dashboard` 后返回 Data-Dense Dashboard，用于表格筛选、状态、治理密度。其 Enterprise Gateway 营销模式未采用。配色沿用 Compass 已有品牌并调整可读性。
- UX 查询 `keyboard focus modal` 支持可见焦点与焦点不被遮挡；Next.js 查询仅作为未来实现参考。本次交付使用原生 HTML/CSS/JS，无构建依赖。
- 弹窗行为依据 [WAI-ARIA Dialog Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：焦点进入弹窗，Tab 留在弹窗，Esc 可关闭，关闭后返回触发控件。
- 图表依据 [WAI Complex Images](https://www.w3.org/WAI/tutorials/images/complex/)：提供简短描述及可访问的数值、结论和表格替代。

以上是本产品对指导资料的取舍。原始搜索输出未作为另一份设计真源保存。

## 2. 一个系统的体验架构

### 2.1 统一框架

| 区域 | 桌面规则 | 小屏规则 |
|---|---|---|
| 一级导航 | 左侧 60 px 窄图标栏；hover/focus 显示标题，当前项保持选中 | ≤900 px 保留窄栏，二级使用浮层；≤720 px 由菜单按钮呼出导航 |
| 二级导航 | 默认固定展开，260 px；≤1180 px 为246 px；展开占位、收起隐藏 | ≤900 px 强制浮层；≤720 px 一级56 px、二级264 px，按窄屏可用宽度收缩 |
| 身份与范围 | 顶栏保留企业/岗位/数据范围；导航底部提供个人设置与设计指南 | 保留可识别身份和当前范围，减少辅助文字 |
| 主内容 | 宽度扣除当前固定导航；浮层不改变主内容宽度；首页居中 | 单列，导航打开时使用可关闭遮罩，正文无横向溢出 |
| 会话工作区 | 中间会话最大 760 px；消息流独立滚动，输入固定在会话列底部；分析过程、输出、行内产物和授权随消息组织 | 中间对话保持完整；长表格容器内滚动；≤560 px 调整字号与内边距 |
| 临时演示面板 | >1180 px 为原型专用右侧 300 px 可收起区域，与会话间距 28 px；优先显示六个任务的完整静态演示；普通会话另有折叠的旧场景控件 | ≤1180 px 为默认收起的右侧抽屉，宽度 `min(340px, calc(100vw - 24px))`；右上按钮打开，遮罩/Escape/关闭按钮关闭；生产不包含此区域 |
| 弹窗 | 最高88dvh，宽度最大720 px，保留关闭操作 | 视口减32 px，内部可滚动 |

导航尺寸由 [navigation.css](prototype/navigation.css) 的 Token 维护；上述值为本轮实现基线。其他视觉 Token 继续由 `styles.css` 维护。原型“体验身份”用于演示岗位，生产身份与授权由可信服务提供。

### 2.2 一级入口与二级内容

| 一级入口 | 主路由 | 二级内容 / 主要对象 | 当前原型能力 |
|---|---|---|---|
| 分析 | `#analysis` | 首页；新建；标题区搜索图标与弹窗；单行会话按更新时间排序或主题分组；场景库、待我决定 | analyze；待我决定另查review |
| 报告空间 | `#reports` | 独立产物检索、分类、五维状态、版本及传播操作 | assets + 独立动作权限 |
| 插件 | `#plugins` | Skill、Prompt、Agent、模板、数据集；筛选、详情和复用 | 暂复用assets，复用重验数据/工具权 |
| 定时任务 | `#automations` | 固定刷新、自主重新分析、主动监控、每期实例与回执 | automations |
| 看板 | `#boards` | 团队看板、参数化应用、筛选、刷新和发布版本 | 暂复用assets，查询按当前访问者范围 |
| 管理与治理 | 首个获权管理领域 | 控制总览、数据与语义、Agent 与能力、运行与调度、质量与发布、安全与审计、记忆与产物、组织设置 | 八领域分别授权；写操作独立授权 |
| 导航底部 | `#design` | 设计体系与体验指南 | 原型公共说明 |

管理二级沿用 `#admin-overview`、`#data`、`#capabilities`、`#runs`、`#quality`、`#security`、`#memory`、`#organization`。分析场景库沿用 `#scenarios`，待我决定沿用 `#review`，新会话使用 `#chat/<taskId>`。一级图标不会为每个管理领域单独扩展。

模块可见性、动作权限与数据范围分别计算。当前原型的报告空间、插件、看板聚合使用 `assets`；后续生产实施支持三者独立能力配置，并迁移旧授权。独立导出、发布、管理写权限继续有效，审计角色默认只读。导航不授予额外权限。

### 2.3 二级导航状态机

| 状态 | 进入方式 | 布局与交互 | 离开方式 |
|---|---|---|---|
| 固定展开 | 桌面默认；点击固定/展开按钮 | 二级稳定占位，内容随占位调整；列表可独立滚动 | 点击收起，释放二级占位 |
| 收起 | 点击收起 | 只保留一级窄栏；图标title/tooltip可见 | hover/focus预览或点击展开 |
| 临时浮层 | 收起时hover一级120 ms；键盘focus；触屏点击 | 二级覆盖主内容，不重排主内容；指针可跨入二级操作 | 离开一级与二级区域240 ms后关闭；Escape关闭；固定按钮转占位 |

- 120/240 ms 延迟用于避免误触和指针跨越时消失，关闭计时在指针重新进入时取消。
- 一级图标始终有 `aria-label`；标题提示可由hover与键盘focus触发。选中状态不只依赖颜色。
- ArrowRight 从一级图标进入对应二级，Escape 关闭临时浮层并把焦点返回触发图标；固定二级内不会因移开指针自动关闭。
- 二级展开按钮使用明确的“展开侧栏 / 收起侧栏 / 固定侧栏”标签及状态属性。鼠标、键盘和触屏都能进入所有页面。
- 固定偏好保留在当前浏览器；窄屏强制浮层时不覆写桌面偏好。返回桌面恢复已保存展开状态。
- 角色或权限变化后，固定栏与浮层同步过滤；失效路由显示权限态。导航状态变化不重建会话。

### 2.4 分析首页与完整会话

分析首页以居中问题输入框为视觉焦点，主标题上方不放品牌说明，输入框下方不放经营数据更新时间或常驻发送快捷键提示。下方聚合授权内经营看板案例。案例说明当前信号、时间范围和下一动作，可带上下文进入分析。完整会话历史集中在二级栏，避免与首页案例重复堆叠。

分析二级顶部提供“新建分析”。搜索图标位于侧栏标题区，紧邻折叠按钮左侧；点击或 Cmd/Ctrl+K 打开 Alfred 式弹窗。弹窗自动聚焦输入，检索标题与完整 transcript，显示会话标题和命中片段。↑/↓ 移动选择，Enter 打开，Escape 关闭并恢复焦点；无匹配提供清除搜索，权限收缩后重新过滤结果。

会话列表默认按 `updatedAt` 倒序；主题模式按业务主题分组并保持组内时间顺序。每行仅保留单行标题，右侧承载运行加载标记、高亮待授权标记或未读蓝点；提供对应文字与可访问名称。打开会话清除未读，长标题可通过 title 或详情取得全文。hover/focus 显示改名与删除，触屏提供可点击入口；状态和操作都不导致行高变化。

改名表单保留当前标题，空标题不提交，取消恢复原值。删除采用软删除并提供撤销；当前会话删除后返回分析首页，列表与搜索移除该项，恢复后保持原 taskId、历史和权限。报告空间的产物与审计独立保留，删除不会自动取消运行。零会话引导新建；空工作区可提供 3 条明确标记的合成示例。

点击会话进入 `#chat/<taskId>`，中间以完整对话为视觉主体，按消息组织用户输入、可展开分析摘要与工具记录、Agent 输出、行内产物卡、消息操作和人工决定，底部保持续聊输入。历史较长可用折叠或分段加载控制密度，用户必须能查看全部记录。续聊在所选会话内追加消息，并保留已确认范围；相同模板的新问题创建独立 taskId，不覆盖另一会话。

`#home`、`#assets`、`#tasks` 和 `#scenario/Sxx` 继续兼容。旧浏览器状态迁移至独立会话，`scenarioId` 标识方法模板。刷新和前进/后退按taskId还原对应会话；权限改变时隐藏受限历史，不改写历史范围。

### 2.5 页面模板

1. **Analysis Home**：居中输入与上下文 → 聚合经营看板案例 → 可继续工作入口。
2. **Conversation**：完整消息历史 → 消息内可展开分析过程/工具 → 输出与行内产物 → 消息操作/人工授权 → 底部续聊输入。右侧演示面板只在原型中出现。
3. **Report Space**：分类/搜索 → 独立产物卡 → 版本与五维状态 → 编辑/复算/刷新/传播。
4. **Plugin Library**：五种类型 → 搜索与筛选 → 前提/版本/输入/依赖详情 → 在分析中使用。
5. **Board Space**：看板列表 → 参数/数据绑定 → 查询与图表 → 刷新/发布版本。
6. **Operations List**：标题与主操作 → 摘要 → 筛选 → 数据表 → 编辑与影响确认。
7. **Decision Detail**：类型 → 对象版本/范围 → 已完成工作和证据 → 选项/影响 → 决定。
8. **Settings**：相关管理域 → 已发布配置和草稿 → 校验 → 保存/评测/发布。

## 3. 视觉 Token

公共视觉 Token 唯一维护于 [styles.css](prototype/styles.css) 的 `:root`；双层导航布局 Token 维护于 [navigation.css](prototype/navigation.css)。模块样式消费语义变量，新增组件不得自行引入相近的品牌颜色。以下登记用于设计评审，调整时与 CSS 同步。

| Token | 当前值 | 作用 |
|---|---|---|
| `--canvas` | `#F8F9F6` | 页面底色 |
| `--surface` | `#FFFFFF` | 产物、表格与弹窗 |
| `--surface-subtle` | `#F1F3EF` | 表头、代码、次级区块 |
| `--ink` | `#202B27` | 主文字 |
| `--muted` | `#62716A` | 辅助文字 |
| `--primary` | `#1C5145` | 主操作、选中、品牌 |
| `--primary-hover` | `#123B32` | 主操作悬停 |
| `--primary-soft` | `#E5EEE7` | 浅色强调 |
| `--accent` | `#DCEAB8` | 少量自然色点缀 |
| `--border` | `#DCE2DA` | 结构分隔 |
| `--border-strong` | `#A7B4AA` | 控件轮廓 |
| `--success` / soft | `#286344` / `#EAF4EC` | 校验通过、成功 |
| `--warning` / soft | `#825719` / `#FFF4DD` | 待决定、数据晚到 |
| `--danger` / soft | `#A33F39` / `#FCECE8` | 拒绝、失效、危险操作 |
| `--info` / soft | `#315D83` / `#EAF1F8` | 运行中、方法信息 |

状态同时有文字和标记。颜色不能独自承载意义。普通正文目标对比度至少 4.5:1；非文本控件/焦点至少 3:1。本次交付以浅色为验收主题，深色主题在完成独立配色与验证后加入。

### 3.1 排版

| 层级 | 字号 / 行高 | 规则 |
|---|---|---|
| 首页主标题 | 38 / 1.35，移动 32 | Songti SC / STSong / Georgia；一次使用 |
| 页面标题 | 29 / 1.35，移动 25 | 系统字体，600–650 |
| 区块标题 | 19 / 1.5 | 600 左右 |
| 组件标题 | 15 / 1.5 | 600 左右 |
| 正文 | 14 / 1.65；移动基础 16 | 系统字体，400 |
| 紧凑表格与控件 | 12–13 / 1.5 | 桌面高密度内容；关键结论使用正文层级 |
| 辅助元信息 | 10–12 / 1.65 | 仅辅助；完整含义在正文可取得 |
| KPI | 28 / 1.4 | 等宽数字，单位分级 |
| 代码 | 12 / 1.7 | SFMono-Regular / Consolas |

系统字体优先，原型不请求外部字体服务。中文自然换行，长 ID/URL 允许折行，主布局禁止因长文本变宽。

### 3.2 尺度与动效

- 间距：4、8、12、16、24、32、48 px；相关信息靠近，跨区域增大间距。
- 控件圆角 7–8 px，卡片 10–12 px，输入容器 15 px。
- 控件通常高 38–44 px；手机主要触控目标至少 44 px。
- 只有浮层与输入容器使用克制阴影，常规布局以边框和留白组织。
- 微反馈 140 ms；层级切换 220 ms；尊重 `prefers-reduced-motion`。
- 动画表达状态变化，不制造虚假运行进度。生产执行进度由事件驱动；原型步进明确为演示。
- SVG 图标统一 24×24 视图、1.6 线宽；原型为本地绘制线性图标，无 emoji 或外部图标依赖。

## 4. Agent 交互语法

### 4.1 问题输入

用户可输入自然语言、引用指标、添加 CSV 上下文、选分析深度。Enter 发送，Shift+Enter 换行，中文输入法组合输入不触发提交。首页输入框不提供手动缩放手柄。空输入保持焦点并显示可执行提示。原型 CSV 仅本地读取行数/列名，限制 2 MB，不上传。

每次新建分析创建独立会话；用户从历史会话续聊时只追加当前taskId的消息。系统自动补齐可信上下文；会影响结论的歧义以选项展示。澄清完成后复用相同范围。原型的关键词路由用于发现合适场景，不能视为已实现语言理解。

### 4.2 可观察过程

对话消息内的“分析过程”（thinking）提供展开入口，完整呈现已记录的任务目标、计划、方法摘要、工具记录、证据与修订。每个步骤可继续展开名称、状态、输入范围、结果引用和下一动作。模型私密原始思维链不进入界面或产品存储。原型模拟这些运行事件；生产展示真实事件，不得生成与实际行为无关的过程文本。

- 已完成项与待执行项视觉区分。
- 并行分支显示各自边界与状态，由主任务汇总。
- 假设包含“支持”“不支持”“待验证”，保留反证。
- 重规划说明变更原因、重跑步骤、保留结果和失效授权。
- 取消请求与取消确认分开；页面关闭不等于取消。
- 部分完成保留可用结果，明确原目标尚未解决。
- 证据不足、数据延迟、零记录、权限拒绝、运行错误分别表达。

### 4.3 十二类组件组合

| 场景 | 核心组合 | 必须显露的限制 |
|---|---|---|
| S01 快速问数 | 答案 KPI + 条件摘要 + 结果表 + 查询引用 | 单位、时间、口径、数据截止 |
| S02 交互探索 | 条件条 + 下钻/分支 + 图表/表格 | 替换与追加条件可追踪 |
| S03 文件清洗关联 | 文件剖析 + 规则选择 + 处理前后对照 + 代码 | 重复、缺失、匹配率、粒度 |
| S04 对账 | 差额桥接 + 已解释/剩余项 + 修复提案 | 总差额可对回，不自动改公共口径 |
| S05 异动诊断 | 新鲜度 → 贡献分解 → 假设/反证 → 报告 | 贡献、相关、因果分别表达 |
| S06 深度专题 | 问题树 + 并行子任务 + 重规划 + 综合报告 | 预算与未解决子问题 |
| S07 预测 | 基线 + 预测区间 + 回测表 + 情景参数 | 预测跨度与回测跨度一致 |
| S08 随机实验 | 分流/质量 + 效应区间 + 护栏 + 决策标准 | 不将不显著直接写成无效果 |
| S09 观察性因果 | 干预定义 + 识别条件 + 诊断 + 敏感性 | 条件不足时明确受阻 |
| S10 周期报告 | 定义 + 数据就绪 + 每期版本 + 投递回执 | 固定刷新与重新分析分别记录 |
| S11 主动监控 | 规则 + 异常事件 + 冷却/去重 + 恢复 | 检测器健康与业务恢复分开 |
| S12 参数化应用 | 参数 + 数据绑定 + 看板预览 + 发布 | 按访问者授权查询 |

图表需要标题、轴/单位、图例或直接标注、范围和数据截止。趋势保持同一量纲；贡献比较避免把不同分解直接求和；预测区间需要方法说明。每个复杂图表附文本结论或数据表。

### 4.4 人工决定

| 类型 | 主按钮建议 | 决定对象 |
|---|---|---|
| 业务澄清 | 采用此口径 | 目标/约束/事实 |
| 计划对齐 | 按此范围继续 | 方法/范围/预算 |
| 执行授权 | 授权此动作 | 身份、参数、目标、预算、有效期 |
| 结果复核 | 采纳此版本 | 产物内容/方法 |
| 发布授权 | 发布此版本 | 版本、受众、目的地 |

请求卡位于中间对话的相关消息，先展示可判断的结果、对象版本、范围与影响，再提供确认/拒绝操作。受控步骤等待有效决定，普通续聊仍可补充信息。拒绝、部分同意、超时、撤回有独立记录。超时保持未授权。需要新授权的变化使旧批准失效。业务复核不得扩大数据权限。正式授权交互不依赖右侧演示控件。

### 4.5 产物与版本

计算、验证、人工采纳、发布、新鲜度采用五条独立状态轴。保存、编辑、复算、刷新、重分析、导出、发布各有独立动词和结果；编辑新建版本，保护人工修改；计算变化使相关验证失效。

图表、表格、代码、证据与报告先以内联卡片出现在对应消息中，再进入独立详情；卡片显示类型、标题、版本和可执行动作，返回后保留会话位置。消息复制和反馈绑定当前消息；反馈可关联产物版本，重试和继续保留旧记录及人工修改。

产物详情保留结论、来源、指标版本、运行、方法、依赖和权限。发布只针对指定版本/受众。撤回在线链接与收回已导出副本分别说明。导出与发布能力独立于查看。

### 4.6 临时演示面板

本节只约束 HTML 原型的评审工具。右侧“场景演示”列出六个任务卡：简单分析、敏感访问授权、建议与写库授权、PPT、Skill 与定时任务、闲聊引导；点击一次展示完整对话与产物。中间对话不放案例导览、状态注入按钮或演示步骤控制；收起面板不影响正式会话操作。迁入生产时移除面板及模拟推进逻辑。

六个重点任务无需播放动画。示例默认呈现完整成功对话；授权卡的“重新选择授权结果”支持等待、同意和拒绝，未同意时不展示后续执行结果。简单分析直接展示富文本与图表，PDF / Word 下载随回答呈现；PPT 提供五页预览与下载。旧流程控件只在普通会话的“更多分析与状态演练”折叠区保留。每次选择创建独立会话，其他会话保持独立。面板明确说明自动人工授权仅为本地合成演示，自动决定记录携带模拟标记；用户正常对话仍通过行内授权卡决定，不借演示状态扩权或执行外部动作。

视口宽度 >1180 px 时，面板作为可收起的右侧 300 px 常驻区域，与最大 760 px 的会话区间距 28 px。≤1180 px 时改为默认收起的右侧抽屉，宽度为 `min(340px, calc(100vw - 24px))`，由会话右上按钮打开；点击遮罩、Escape 或关闭按钮均可关闭。打开后焦点进入并约束在抽屉内，关闭后返回触发器。抽屉转换时长 180 ms，减少动态偏好下关闭转换；≤720 px 调整会话高度，≤560 px 调整移动端字号与内边距。

中间消息流独立滚动，输入固定在会话列底部；关闭抽屉后输入与消息动作持续可访问。尺寸由 [scenarios.css](prototype/scenarios.css) 统一维护。面板标题、自动决定开关、模拟提示与消息前缀采用 PRD 的 `COPY-22–24`。

## 5. 组件规范

| 组件 | 正常行为 | 异常与键盘要求 |
|---|---|---|
| Button | 每个区域一个主要动作，动词明确 | 禁用有原因；提交期间防重复 |
| Status | 文字、颜色、标记共同表达 | 不使用泛化“正常/异常”替代原因 |
| Table | 列名、单位、关键字段对齐 | 空态、加载、错误、无权分别出现；小屏容器滚动 |
| Tabs | 同一对象内分组；选中明确 | 键盘可达；不能仅靠颜色表达 |
| Form | 可见标签、帮助信息、保留输入 | 错误邻近字段；恢复方式具体 |
| Dialog | 标题、正文、关闭和主动作 | 焦点约束、Esc、恢复焦点；危险操作不默认聚焦 |
| Toast | 简短结果反馈；会话删除提供可点击撤销 | 不作为唯一错误/业务状态载体；撤销可由键盘到达 |
| Conversation Row | 单行标题、状态、hover/focus 管理动作 | 加载/待授权/未读具有名称；超长标题可取得全文；触屏能改名和删除 |
| Search Dialog | 标题与全文检索、命中片段、当前选择 | 自动聚焦；↑/↓/Enter/Escape；关闭恢复焦点；空态与撤权过滤 |
| Process Disclosure | 消息内分析摘要与逐项工具记录 | 展开状态可辨认，失败与未执行区分；不披露模型私密原始思维链 |
| Inline Artifact | 消息关联的产物卡与独立版本详情 | 返回会话位置；权限与版本再次检查 |
| Evidence | 与结论相邻，可展开 | 展示数据范围、抽样/截断、来源与时间 |
| Run Controls | 启动、暂停、取消、恢复 | 请求与确认分开，重复事件不产生重复动作 |
| Permission Matrix | 功能与动作分别勾选 | 保存后立即反映菜单，直接路由仍检查 |

## 6. 文案与状态

最终业务文案由 PRD 的文案契约维护，原型按动作语义消费。以下是设计约束：

- 用“数据晚到，等待更新”表达时效问题；用“当前范围无记录”表达空结果。
- 用“当前身份无法访问此功能”表达导航权限；提供联系管理员的路径。
- 用“已请求取消”与“已取消”表达两阶段状态。
- 用“已生成，验证未通过”保留产物与验证差异。
- 用“已同意发布 V3 给经营管理组”明确授权对象；避免笼统成功。
- 错误要说明发生位置、保留的结果和可执行恢复动作。
- 所有业务数值标为合成示例；用户工作界面只在全局保留简短原型标记。

## 7. 响应式、无障碍与验证

桌面 1440×1000、平板 768×1024、手机 390×844 和横屏 844×390 是原型检查目标；另检查 375 px、减少动态效果和 200% 字号。卡片在小屏变单列；长表格独立滚动；关键操作不依赖 hover。所有表单、图标按钮有名称，装饰图标 `aria-hidden`，状态更新通过 live region 宣告。

## 15. home 官网视觉扩展

2026-10-20：官网使用 `apps/home`，延续本规范的墨绿 `#1c5145`、暖白 `#f8f9f6` 和浅绿 `#dceab8`。首页采用深绿全屏 GhostFibers 动画、宋体叙事标题与绿色邻近色光点。产品页按企业经营、商品渠道、经营复杂性、岗位需求、课程情节、原型、Agent 挑战组织七屏纵向叙事；一屏突出一个重点，目录悬浮右侧，使用关系图、品类图标、表格、图表、场景切换与真实 iframe。架构与脚手架页沿用分屏叙事；课程和学习页使用紧凑中文标题、页内目录、必要章节号和下一页入口；全站共享横向导航，不设置装饰英文标签、大号页码或重复页序。营销展示动效仅用于官网，日常分析工作台继续采用安静的会话布局。

基础组件由 shadcn/ui 提供，字体保持本地系统字体；动画可暂停，遵循 Reduced Motion，缺少 WebGL 时使用静态渐变降级。移动端采用 Sheet 导航与单列内容。具体组件、信息布局与性能边界见 [home App 设计](home-app-design.md)，实际实现见 [home README](../../../apps/home/README.md)。

顶部导航取消底部分割线。页面滚动距离严格大于导航栏实测高度时（桌面 80 px、小屏 68 px），以半透明底色、背景模糊和柔和高光呈现玻璃质感；深色首页和浅色内容页分别适配。回到顶部恢复实色背景，切换保持导航高度稳定。减少透明度偏好及不支持背景模糊时使用实色背景；减少动态效果时缩短过渡。具体参数与模板感诊断见 [home App 设计](home-app-design.md)，文案和布局改进已按用户确认实施，随后按用户要求，架构与脚手架采用分屏叙事；课程查询和开工清单继续前置。

架构页以“八项挑战 → Runtime / Harness 与核心目标 → 架构原图”形成三屏；脚手架以“技术栈、Monorepo、规范、流程、AI Infra、数据脚本、环境”形成七屏。与产品页共用右侧 44 px 命中区域的圆点导航，悬停 / 聚焦显示中文章节，当前项用大小与颜色共同标识。暖白、浅绿和深绿随主题切换，不引入独立配色体系。屏内使用图标、真实目录关系、版本矩阵与合成数据图表；完整命令和后续选型可展开查看。手机自然增高并纵向重排，减少动画时正文和图表直接呈现。
