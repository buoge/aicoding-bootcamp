# Compass HTML 交互原型

[打开原型](index.html) · [完整 PRD](../../spec/PRD.md) · [设计体系](../ui-ux-design-spec.md) · [验证记录](../../test/prototype-verification.md)

这是一个统一 Web 系统的可运行产品原型，面向虚构的行野运动集团。涵盖分析会话、报告空间、插件、定时任务、看板、部门管理和系统治理；全部使用合成数据与浏览器本地状态。

## 运行

直接用现代浏览器打开 `index.html`，无需构建、依赖安装或注册账号。保留同目录 CSS 和 JavaScript 文件即可离线运行。

也可以从 Compass 工程目录启动：

```bash
python3 -m http.server 8790 --bind 127.0.0.1 --directory mai-specs/999-compass-product-course-landing-app
```

访问 <http://127.0.0.1:8790/design/prototype/>。以本需求目录为服务根时，设计规范与 PRD 的相对链接也可访问。

首次打开进入登录页，点击内置账号即可按对应角色进入，无需密码。六种身份覆盖集团经营负责人、业务分析师、华东部门管理者、企业管理员、平台运行维护者和安全审计员；前四种默认进入分析首页，运维与审计身份进入控制总览。登录状态保存在当前标签页的 sessionStorage，刷新保留所选身份；左下角头像 →「注销当前账号」返回登录页。手机端先展开导航，再点击头像。未登录时访问内部链接或浏览器后退仍返回登录页，登录后进入该身份的默认首页。顶栏仍可切换体验身份，并同步当前登录身份。

登录页左侧复用 home 首屏的绿色 GhostFibers 动画，保留相同配色、速度与光纤参数。右上角可暂停/播放；遵循系统减少动态效果设置，不支持 WebGL 时显示静态渐变。登录后释放动画资源。

业务状态保存在 localStorage，刷新页面保留；注销保留已保存的分析、报告和配置，清空输入草稿与附件。HTTP 与 file 打开方式拥有不同的存储空间。左侧图标栏底部“设计体系”提供恢复初始状态入口。浏览器禁用存储时可继续体验当前页面，但不能跨刷新恢复。

## 建议体验顺序

1. 登录“业务分析师”，打开任意分析会话。
2. 右侧“场景演示”列出 6 个重点任务，点击“演示”立即展示完整对话、各轮工具调用与最终产物，无需等待播放。
3. 简单分析直接显示含图表的富文本回答，可下载真正的 PDF / Word 文件；PPT 场景提供 5 页预览和可编辑 PPTX 下载。
4. 访问授权、数据库写入和 Skill / 定时任务场景默认展示带“示例已同意”标记的完整成功记录。点击授权卡的“重新选择授权结果”，可体验等待、同意和拒绝；等待或拒绝时后续工具与回执不出现。
5. Skill 场景保留三次相似任务的依据、资产内容、定时阅读任务的范围/时区/预算/有效期，以及暂停/恢复操作。所有动作均为当前会话中的本地合成演示。
6. 闲聊场景先回应，再介绍能力，并提供分析与 PPT 场景快捷入口。

六个任务分别为：简单分析、敏感数据访问授权、决策建议与行动、分析并生成 PPT、沉淀 Skill 与定时任务、闲聊与能力引导。每次选择创建独立会话，历史记录、草稿与授权选择可恢复。演示内输入新问题会开启独立普通分析会话。

原有 S01–S12 分析模板仍可从案例页进入。普通会话的演示面板底部“更多分析与状态演练”保留旧流程与边界控件，默认折叠；六个重点演示中不显示这些控件。

## 导航与会话

一级导航依次为“分析、报告空间、插件、定时任务、看板”，另有按权限显示的“管理与治理”入口。图标悬停显示名称。桌面二级侧栏默认固定，可用右上角按钮收起；收起后悬停一级图标，二级内容以浮层出现，移出后关闭，固定时为主内容留出空间。键盘聚焦一级图标也可展开浮层，右方向键进入，Esc 关闭。手机通过顶栏菜单按钮展开导航。

| 入口 | 路由 | 二级内容 |
|---|---|---|
| 登录页 | `#login` | 六种内置角色账号，点击即进入 |
| 分析首页 | `#analysis` | 新建分析、会话搜索、按时间/主题显示全部获权会话、分析案例、待我决定 |
| 分析会话 | `#chat/<taskId>` | 完整用户/Agent 对话、每轮事件与结果记录、当前产物、继续追问 |
| 报告空间 | `#reports` | 分析报告、图表与视图、数据结果、最近产物 |
| 插件 | `#plugins` | Skill、Prompt、Agent、报告模板、数据集 |
| 定时任务 | `#automations` | 我的定时任务、创建、运行记录 |
| 看板 | `#boards` | 经营总览、渠道表现、库存健康 |
| 管理与治理 | 原有八个管理路由 | 控制、数据、能力、运行、质量、安全、记忆、组织 |

`#home`、`#assets`、`#tasks` 和 `#scenario/S01`～`S12` 等旧入口继续有效。同一场景的新提问有独立 taskId；进入旧会话后可继续分析，其他会话不被覆盖。会话中的分析由本地模板模拟。较早原型没有逐轮保存 Agent 回复，迁移时会明确提示缺少的历史回复。

侧栏会话采用单行标题。右侧分别显示运行中的旋转图标、待授权或待确认标签，以及未读蓝点；打开会话后清除未读状态。鼠标悬停或键盘聚焦时显示改名、删除按钮，触摸设备直接提供操作。删除会话会从列表和搜索隐藏，侧栏支持撤销，报告空间中的已存产物保留。

放大镜位于侧栏折叠按钮左侧。点击或使用 `⌘ / Ctrl + K` 打开 Alfred 式搜索弹窗，可匹配标题、主题和完整消息；用上下方向键选择、Enter 打开、Esc 关闭。搜索结果遵循当前身份和数据范围。

## 对话与演示面板

中间区域始终承载完整会话：右对齐的用户消息、Agent 回复、可展开的分析摘要和工具执行记录、行内授权与错误恢复、带版本的产物卡片，以及底部追问输入框。回复可复制、反馈、重新生成；编辑用户消息会创建独立分支，原会话保留。

“Thinking”使用面向用户的分析过程摘要，包括计划、证据、检查结果和工具事件；原型不声称展示模型的私有内部推理。历史回复保留各自产物快照，重新生成或继续追问不会覆盖旧版本。

右侧“场景演示”默认只展示六个任务。点击后完整对话一次出现，图表和关键产物直接展开。桌面面板可收起；宽度不超过 1180 px 时使用默认关闭的右侧抽屉，支持遮罩、关闭按钮、Esc、焦点约束与恢复。选择场景后窄屏抽屉关闭，返回对话起始位置。

示例的授权和执行回执均带合成演示标记。选择示例不创建真实权限、数据库记录、插件或后台任务；重新选择授权结果只更新当前演示分支。同意后才呈现受控工具的执行与结果，拒绝保留已完成分析。当前身份和数据范围门禁继续生效。

下载内容的单一来源为 [demo-content.js](demo-content.js)，[生成脚本](../../test/build-demo-downloads.py) 生成 [demo-downloads.js](demo-downloads.js)。文件嵌入本地脚本，直接打开 HTML 和官网分发副本均可下载，不依赖 CDN 或后端。PDF、DOCX 包含正文和图表，PPTX 包含 5 页可编辑文字及原生图表。修改样例数据后运行：

```bash
uv run --no-project --with python-docx==1.2.0 --with python-pptx==1.0.2 --with reportlab==4.4.9 python mai-specs/999-compass-product-course-landing-app/test/build-demo-downloads.py
```

生成器需 macOS 中文字体（PingFang / 黑体 / 宋体）或 Linux Noto Sans CJK 字体；仅生成时需要这些依赖，浏览器运行无需安装。官网开发副本更新使用 `node apps/home/scripts/prepare-assets.mjs`。

### 管理入口

控制总览、数据与语义、Agent 与能力、运行与调度、质量与发布、安全与审计、记忆与产物、组织设置。数据接入、指标版本、技能/工具、模型、沙箱、运行、配额、成本、追踪、评测、组合发布/回滚、记忆、产物传播、身份与角色均有可操作的雏形。

功能可见能力与 `governance-write`（治理写入）、`export`、`publish`、`audit-sensitive` 分别配置。所有权限均为原型模拟；生产环境必须以服务端身份、策略和数据访问检查为权威。

## 原型边界

- 自然语言通过本地规则选择演示场景；不调用真实模型。运行可手动推进或自动播放，模拟运行事件、工具结果和方法产物。
- 页面、配置、版本、恢复和下载有实际本地状态反馈。数据库查询、代码沙箱、统计分析、企业登录、服务端多租户隔离、定时后台执行及外部通知均未接入。
- 数据源“测试连接”只校验演示表单，不发起连接；访问凭证不持久化。
- 文件解析只读取本地 CSV 的列名与行数，场景分析使用预置合成数据。解析不承诺完整 CSV 方言支持。
- 页面里的“发布”“投递”“回滚”改变本地演示记录，不产生企业系统或网络副作用。
- 真实性能、统计方法正确性、权限安全、跨进程恢复、并发幂等、完整屏幕阅读器兼容需后续工程验证。

## 复跑检查

检查脚本需要开发机可用的 Playwright 和 Chrome/Chromium，运行产品原型本身无需这些依赖。默认通过 file URL 打开，可用 `PROTOTYPE_URL` 指向静态服务。

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
CHROME_BIN='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
node mai-specs/999-compass-product-course-landing-app/test/prototype-check.mjs
```

六个重点演示的独立检查使用同样环境变量，将命令末尾替换为 `test/static-demo-check.mjs`。

也可在可解析 `playwright` 包的环境从本需求的 test 目录执行 `node prototype-check.mjs`。测试只写浏览器隔离上下文和系统临时目录，不修改业务源文件。
