## 检查中发现并修复

1. 模块可见权曾允许审计员写入治理配置。加入独立 `governance-write`，页面与 handler 同时检查。
2. 切换到华东管理者后可能继续查看其他区域旧结果。改为保持原范围、隐藏旧结果、拒绝后续动作；授权范围内新分支不继承旧数据/批准。
3. 资产详情曾使用统一诊断文案。改为按产物快照读取结论、方法、数据范围和来源，预测/实验/因果产物保持各自内容。
4. 编辑已发布产物可能沿用验证与发布状态。现在新文字/逻辑版本进入待验证、待决定和草稿，旧决定失效。
5. 同类型新提问曾复用旧任务。现在生成独立 taskId，归档历史契约与事件，产物 ID 绑定 taskId 与版本。
6. 弹窗键盘循环曾在边界失去焦点。加入显式焦点约束，并验证关闭后的恢复路径。
7. 输入框失焦的 change 事件曾命中父 form，可能重复创建分析。代理现在只处理实际带 data-action 的表单控件；提交只通过 submit 或 Enter 触发。
8. 收起的侧栏与手机图标栏现在使用 inert 隔离键盘焦点；手机抽屉打开时背景不可聚焦。
9. 搜索输入使用 `type=search` 时，浏览器可能先消费 Esc 清空输入。现在显式关闭搜索弹窗，并恢复焦点。
10. 自动演示绑定当前 taskId、路由、身份与数据范围；每次渲染和定时推进重新检查，切换上下文后暂停旧演示，避免推进另一条同类型会话。
11. 删除的会话从列表与搜索隐藏，直接访问显示删除空态；旧场景入口另建示例，已删历史保持可撤销。未授权会话标题不会出现在页面标题中。
12. 抽屉焦点循环排除折叠 details 内部的隐藏控件，关闭后返回面板按钮。程序滚动即时定位最新消息，未发送内容不被面板操作或自动演示刷新清空。

## 通过结论的边界

此记录证明产品原型的交互可运行、状态可观察和关键前后模块一致。数值、工具输出、评测、发布、投递及治理操作均为明确的本地模拟。

下列事项仍需生产实现与专门验收：真实身份与服务端权限隔离、SQL/代码安全、统计方法正确性、全量数据指标对账、并发与跨进程恢复、实际幂等与外部回执、性能容量、日志保留/删除、完整屏幕阅读器测试与深色主题。
