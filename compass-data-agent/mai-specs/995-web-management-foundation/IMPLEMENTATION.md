浏览器实测旧新建按钮高 54.75px、15px 字号，分组项高 38px；已改为原型的桌面 42px / 13px、分组项 29px，移动端分别为 44px、36px。统一二级图标 18px / 1.6 线宽、一级图标 21px / 1.7 线宽，以及标题、内边距、圆角、选中和悬停状态。新建定时任务沿用同一创建按钮样式；分析三个已删除入口保持移除。
