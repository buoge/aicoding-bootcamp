## 一句话描述

实现 Web 工程基座并搭建原型的完整界面框架；分析、报告、看板及其他 Agent/Memory 业务先保留空页面。

## 背景

Compass 已有完整产品规格与交互原型，当前需求从 M0 工程链路演示扩展。先落实登录、会话、组织权限、设置、审计与 Web 持久化，同时将全部导航、布局、路由和页签迁入真实 Web 工程，为逐模块接入业务准备基础。已按 8 表方案完成按用户配置权限、数据库会话、工程 CRUD 和原型框架；代码复评及本期 21 项 AC 验收通过，实际证据见 [实施记录](IMPLEMENTATION.md)。

## 关键决策

以下按阶段保留历史；最后一条登记本次最终验收。

- 2026-10-25 初始讨论：先规划非分析管理功能，执行能力留到后续。初稿将多个 Agent/Memory 业务纳入实现，范围超过用户后续明确的 Web 基座主线。
- 2026-10-25 职责补充：文件上传、正文/表格/元信息解析、OCR、主动字段/记忆候选抽取及确认归 Memory。用户确认的是能力边界，本期不实现相关服务。
- 2026-10-25 最新范围：Web 工程基座为本期重点；补齐原型全部界面框架，分析、报告、看板等 Agent 相关业务先空页。PRD 和本期 AC 已按此修订。
- 原型覆盖包含五个业务入口、八个管理领域、31 个原有页签及个人入口；普通业务页面不依赖 Agent/Memory 启动，不提供模拟业务成功。
- 2026-10-25 技术设计：用户调用 `my-create-design`，并明确“系统的UI设计，参考原型系统的设计”。技术方案沿用原型视觉与交互，完整登记 Web 身份、组织权限、数据、路由/API、部署及实施任务。
