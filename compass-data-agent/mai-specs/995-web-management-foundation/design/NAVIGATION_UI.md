Web 的 [navigation-icons.tsx](../../../apps/web/src/components/shell/navigation-icons.tsx) 集中登记图形和菜单映射，[globals.css](../../../apps/web/src/app/globals.css) 维护导航尺寸；图标随菜单项映射，使用原型的相同路径。这里记录规范与有意保留的产品差异，运行验证见 [实施记录](../IMPLEMENTATION.md)。

## 交互

- 分析模块顶部显示 Compass 与“分析空间”；其他模块显示对应一级标题。正文不重复模块标题。
- 固定侧栏随点击的一级菜单切换；收起时，悬停 120ms 展开对应模块的浮层，页面地址与当前内容保持；跨到浮层可继续操作。
- 移出导航区域 240ms 后关闭浮层；焦点位于侧栏内时保留。点击外部或将焦点移出导航立即关闭。
- 一级菜单获得键盘焦点时展开浮层；右方向键进入二级导航；Esc 收起并将焦点交回来源一级菜单。
- 将其他模块的预览固定时，同时打开该模块。保存中禁用按钮，保存失败保留重试提示；切页继续遵循未保存草稿确认。
- 视口 ≤900 时采用浮层导航；点击当前一级项目可再次展开。移动抽屉包含完整一级栏与二级栏，焦点限制在抽屉内，关闭后回到展开按钮。
- 所有页面入口继续使用 SPA 导航。新建分析打开或重置问题编辑器，已有草稿继续遵循离开确认。

## 本期明确差异

用户已要求删除“分析案例、待我决定、全部分析会话”三个侧栏入口。Web 保留工作空间切换、真实身份与权限、全局页面搜索和真实通知。分析执行、会话内容搜索、动态产物/任务列表及会话改名/删除随对应业务接入，不在此次 UI 修正中扩展后端范围。
