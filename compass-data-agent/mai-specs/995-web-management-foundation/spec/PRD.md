## 1. 背景与目标

### 1.1 当前有效范围

**本期交付 Web 工程基座和原型系统的完整界面框架。** 本地账号登录、会话、租户/空间、直接成员关系、默认角色与个人权限、个人设置、通用配置和 Web 操作审计需要真实实现。分析、报告、看板、插件、定时任务，以及依赖 Agent / Memory 的管理业务先提供可访问的空页面，后续逐模块补齐。

用户最新纠正具有优先级：Memory 的文件上传、解析、抽取属于**目标架构职责**，本 Feature 不实现 Memory，也不要求 Agent 的业务接口、数据库或业务任务。文件能力的目标范围包括正文/表格/元信息、OCR、主动结构化字段/记忆候选抽取及确认；这些属于后续业务 Feature。

用户在数据设计评审后明确同意“按这个简化方案优化”。本轮同步修订 PRD 和技术方案：Web 采用 8 张业务表，企业 SSO、组、动态角色/委派、邀请、服务身份登记和未来业务范围元数据退出本期。完整原型框架和真实隔离继续保留；本轮不实施代码。

2026-10-26 用户追加“需要支持给每个用户单独配置权限”的管理能力。当前范围更新为**默认角色模板 + 按用户、按租户/空间保存权限清单**；用户会话继续保存在PostgreSQL。角色作为填充模板、权限保存为最终清单是本版设计选择，尚未作为用户对该交互细节的单独确认。企业SSO、组、邀请、自定义角色CRUD及通用委派仍延期。

### 1.3 完成定义

1. 用户能够真实登录、选择获权空间、完成 Web 自有管理操作，并在刷新、重新登录、Web 重启后读取已提交数据。
2. 原型的完整应用框架在 `apps/web` 中可用：一级/二级导航、顶栏、头像设置、管理页签、深链与响应式均工作，页面和布局由工程源码维护。
3. 获权用户能进入全部已登记的业务空页面；空页面与无权限、无数据、服务错误分别表达，不显示模拟经营数据或成功操作。
4. 停止 Agent、Memory、Worker 后，登录及 Web 基座仍可工作，空页面仍可打开；不要求模型、文件存储、OCR、向量库或任务执行服务。
5. Web 数据迁移、权限和审计有真实验证；基座完成不意味着分析、报告、看板或记忆业务已交付。

## 3. 核心流程

### BF-995-01 登录与工作空间

```text
登录页 → 校验本地账号密码 → 建立会话并读取当前成员资格 → 选择 / 恢复获权租户和空间
       → 合法目标页 / 默认入口 → 真实 Web 管理页或业务空页面 → 退出
```

无成员资格显示访问说明，不自动建企业或授管理员。默认优先恢复仍获权的目标页；随后按当前个人权限选首个合法入口，默认模板下分别为分析、报告/看板或控制总览；平台管理员可进入平台租户管理。没有任何模块权限时仍可进入本人设置与退出。

### BF-995-02 工程 CRUD 与撤权

```text
获权列表 → 新建 / 编辑 → 校验字段、版本、当前动作权限和目标归属 → 保存到 Web 数据库
         → 操作结果与审计 → 列表刷新 / 再次打开
权限变更或成员停用 → 新请求重新鉴权 → 清除失权页面与缓存 → 返回获权入口
```

成员、管理员资格与个人权限等变更只影响本期 Web 权限。后续 Agent/Memory 的跨服务授权消费另行实现，本期不模拟取消运行、转交报告或撤销记忆。

### BF-995-03 进入待开发模块

```text
点击获权导航 / 管理页签 / 深链 → 保持完整框架和选中态 → 显示该模块空页面
                              → 返回或切换其他页面
```

空页面不请求未来业务 API，不产生业务记录，无“上传成功”“发布成功”等模拟回执。导航可点开；业务执行操作不提供可提交表单。

### 4.3 身份、组织与权限细则

**认证与会话。** 教师通过受管命令创建本地账号与测试身份；用户用登录名和密码登录。使用安全密码哈希、登录限速和统一失败文案，禁止明文保存密码或记录口令。账号名/安全资格不能由个人资料接口修改。会话默认固定有效期 12 小时，可部署收紧；无后台心跳续期。本人可退出或撤销其他会话；受管密码重置、全站停用同时撤销该账号会话。平台资格只由部署工具维护，无公开注册企业或自我提升权限入口。

Web 成员停用、角色或个人权限收紧和会话撤销在下一请求生效；在线前台页面 30 秒内清除已失权视图。后台恢复、重连或浏览器历史恢复时，先复验再显示敏感内容；离线禁写，超过核验时效遮蔽视图。每个受保护请求由服务端读取当前资格；客户端状态不能授权。企业 IdP 接入及其外部生命周期同步延期。

**组织。** 平台管理员登记/停用租户并明确首管理员；平台资格不自动赋予租户业务访问。租户管理员或获空间管理权限的成员维护本租户空间；创建空间不自动授予创建者额外权限。名称 1–80 字、说明≤500字；同租户空间名去空白后唯一。默认空间按本人偏好/首个获权空间选择，不建立租户指向默认空间的配置。切换处理未保存表单，确认后清旧结果、搜索和草稿，迟到响应不得覆盖新上下文。归档保留历史并禁空间业务写，恢复重验权限。

**直接成员关系。** 一个账号可属于多个租户；租户成员必须有效，空间成员必须关联同租户成员。租户角色固定 admin/member，空间保留 analyst/viewer/auditor 模板标识；每个范围一条成员关系及一份个人权限清单。管理员直接添加已有账号、启停租户成员、维护空间成员；重复添加不产生第二条关系，停用后只能显式恢复。组与邀请保留说明区域，不实现操作。成员移除采用停用租户关系或删除空间关系，保留主体和审计。不得通过并发降权/停用失去最后一名有效租户或平台管理员。

**角色与个人权限。** 租户admin保留本租户完整管理能力和全部空间访问，用于授权管理及最后管理员保障；普通member可获得个人配置的权限。analyst/viewer/auditor只作为空间权限的初始填充模板，默认集合沿用现有矩阵。保存后以该用户关系上的权限清单鉴权，后续模板调整不自动改变已有用户。管理员可以为同一模板下的不同用户配置不同权限，例如给某位viewer增加空间审计读取/导出，或去掉某位analyst的插件入口。

权限作用域选择为“整个租户（含全部空间）”或“指定空间”。租户个人清单对该用户的整个租户生效；空间个人清单只对相应空间生效，空间最终权限为两者允许项的并集。空间界面显示来自租户的权限，不能通过取消空间勾选撤销租户授予；需要收窄时先修改租户清单，再给需要的空间分配。清空租户清单保留空间清单，清空空间清单保留租户授予。该规则不引入显式拒绝或角色继承链。

权限目录有限，默认拒绝未知项。平台资格由受管命令维护；租户admin资格及成员/权限分配操作仅租户admin可修改，不作为普通用户可勾选的权限。其他已登记模块/工程读写权限可按目录适用范围授予，不能借权限清单自行晋升admin。admin的个人权限界面只读显示完整权限；需收窄时显式改为member并配置权限，最后管理员保护仍生效。平台资格不自动授予租户访问，个人会话和资料仍只按self判断。

保存权限必须核验当前操作者、目标成员、租户/空间归属、权限目录和版本，记录增减项审计及授权变更通知，并递增授权版本；下一请求按新权限判断，客户端按既有30秒规则清屏。空清单是明确的无直接授权，不能回退到角色默认值。管理员只能配置本期已实现的权限；分析运行、工具执行、文件处理等未来动作不进入可选目录。

**数据范围。** 本期只存实际使用的租户、空间和直接成员关系，不存 region/brand/channel 等未来标签。后续接入受限 SQL/RAG 时按业务消费者设计范围；Web 租户 ID 不直接假定等于零售源租户键。现有零售数据约束保留，本期不宣称已接入行列过滤或产物下载权限。

**未来身份能力。** 企业 SSO、邀请、自定义角色/组、服务身份放在对应界面说明中；不建占位表、不提供模拟保存。后续出现真实企业接入、组织继承或执行身份消费者时，再启动相应 Feature。

### 4.3.1 按用户配置权限的界面与流程

沿用原型 `admin.js` 的复选框网格、左侧配置/右侧结果布局及现有组织页签。在“成员与组”的用户行增加“配置权限”，在“角色与权限”中可选择成员打开同一个编辑器；默认角色模板说明继续可读。仅租户admin可提交权限，具备成员/角色读取权限的普通用户只能查看获权说明。

```text
配置权限：示例成员                当前企业：示例企业
范围：[指定空间：华东]（可切换整个租户）
模板：[分析员 / 只读成员 / 审计员] [应用模板]
模块与操作                        当前有效权限
[✓] 报告入口  [✓] 看板入口         直接授予：报告、看板、审计读取
[✓] 审计读取  [ ] 审计导出         来自租户：插件入口（此处只读）
[清空本范围权限]                  [取消] [保存权限]
```

模板按钮只修改当前草稿，不立即保存；租户范围默认空清单，空间范围提供三个既有模板，也允许从空清单勾选。继承自租户的项单独显示并禁用取消；清空仅清当前范围直接项。提交前展示成员、作用范围、增加/移除项，租户范围明确影响全部现有及未来空间。角色名仅标识初始模板，偏离模板时显示“自定义”；模板变化不自动追加权限。

保存中禁重复提交；失败保留安全草稿，版本冲突显示最新权限并要求重新核对。加载失败时禁编辑；停用成员可保存待生效清单，明确提示启用后才生效；无成员展示空态；切换用户/范围前处理未保存内容。取消或关闭不写数据，返回列表刷新当前权限摘要。键盘可进入全部复选框，焦点离开编辑器后回到触发按钮；窄屏按原型抽屉布局显示。空页入口权限只控制进入页面，不提供尚未实现的执行权限。

### 4.4 个人设置、通用配置、通知与审计

- 个人信息、头像姓名缩写、侧栏/列表偏好、本人会话及站内通知真实可用；“我的记忆”进入空页面。
- 通用配置首版仅包括企业/空间名称、展示时区及允许的界面设置；默认空间仅属于本人偏好；不建立任意 key-value 配置编辑器，不包含模型、工具和调度策略。
- 站内通知只消费 Web 已提交事件，如成员加入、角色/个人权限变化、会话被撤销；持久化已读状态，重复事件不产生重复通知。通知已读不生成新审计或通知。没有通知显示真实空态，未接入的业务事件不伪造。
- 审计覆盖登录/退出、授权拒绝、租户/空间切换、租户/空间成员、角色分配、个人权限和设置变更及审计导出；事件包含主体、租户、动作、对象、结果、时间及关联操作 ID，敏感字段脱敏。
- 审计按租户与当前权限过滤；只读审计员不能修改/删除历史。导出需独立权限，只导出获权工程记录并记录导出事件。无需跨服务审计或对象存储。
- 写操作失败保留输入；重复提交不产生重复对象，版本冲突不能覆盖已提交变更。需审计的管理写入与本地审计在 Web 自有事务边界内保持一致。

## 5. 完整界面框架与页面清单

### 5.4 路由、搜索与兼容

| Memory | 通用文件上传/存储/版本、正文/表格/元信息解析、OCR、主动字段/记忆候选抽取、知识文档及记忆生命周期    | 只登记目标职责；不新增路由、表、对象存储、模型适配器或处理任务 |
| Worker | 按需承载后台执行，通过业务 owner API 更新状态                                                       | 无新增消费/调度逻辑                                            |
| Home   | 官网和原型分发                                                                                      | 无产品改版，不改原型副本                                       |

Memory 的文件内容与 Agent 的报告业务版本分开管理：后续 Agent 保存文件 ID/版本引用，Memory 统一管理原件和派生内容。具体接口、引用权限、删除传播、格式/大小、解析器和抽取模型由后续 Feature 设计，不构成本期承诺。向量/RAG 与对话自动记忆继续后续实施。

按[数据库规范](../../../docs/database-migrations.md)为 `web/main` 登记唯一迁移源、独立版本/账号/配置、完整 SQL、增量 SQL、发布与恢复流程。现有 Agent 三天演示库、998 零售库和 996 文档原样保留；不导入原型浏览器存储。业务必要参考项与合成测试账号分开初始化，明确首个管理员来源并验证幂等。新增真实命令在设计/实施时登记，不虚构已存在的 Web 迁移入口。
