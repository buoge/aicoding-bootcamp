## 一句话描述

根命令统一执行本机 Compose 构建、迁移、启动和验收，提供状态日志与保留数据的停止入口。

## 背景

用户希望补齐部署脚本，减少手动操作并提高本机部署效率。

## 关键决策

- 用户确认：不传参数全量部署，传一个 app 名称只部署该应用。
- [简版技术方案](design/TECH_DESIGN.md) 为需求与 AC 真源，直接进入实施，不另建 PRD。
- [实施与验证记录](IMPLEMENTATION.md) 登记当前检查与未完成的容器验收。
- 本机 Docker I/O 错误和已有开发服务端口占用阻碍真实容器验收；保持 dev。
