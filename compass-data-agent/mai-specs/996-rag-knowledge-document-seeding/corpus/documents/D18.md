# 销售、收入与渠道费用对账口径说明

行野运动集团 · 经营财务组 / 经营分析组

文件号：XY-FIN-R001；版本：1.0。整理日期：2026-10-24。适用范围：经营分析口径；历史制度签发日期未载明。金额以人民币、不含税整数分存储，展示为元时统一除以 100。

## 一、先确定比较对象

对账前固定两份结果各自的业务期间、时间字段、知识截止、区域、渠道及币种。上周下单、上周成功收款和上周交付确认收入对应不同事件，不能只因报表均称“净销售”就直接对齐。

集团经营问数使用交付确认收入及退货接受冲减口径时，应明确展示“交付确认净收入”。如果用户需要净收款，采用成功支付减成功现金退款，并说明使用支付发生期或订单所属期。

## 二、收入与现金的区别

交付确认收入来自实际交付事件；物流失败或尚未交付的订单不得提前确认。退货单件验收接受后产生收入冲减。现金退款是独立过程，可能晚于验收，也可能分多次退回原支付。

因此收入冲减与现金退款不保证落在同一天。对账按差异类别逐项桥接，包括未交付、退货确认与退款时差、订单窗口差异、迟到数据及筛选差异；保留仍未解释的差额。

## 三、成本与费用

销售成本按交付商品原出库批次成本确认。可售退货回库时冲回原成本；判损报废不再冲回该销售成本，也不重复扣一次相同损失。标准采购成本变更只影响对应新采购批次，不追溯重估旧批次。

订单经营变动费用与广告投放分开。订单费用可能属于订单整体，也可能分配到单件，汇总时避免与多行商品连接后重复计费。费用冲回使用负数；广告投放在活动日报另记。

本口径不包含固定租金和人力等全部企业费用。交付净收入减销售成本与已纳入的变动费用，可以形成对应经营贡献口径，不能直接命名为完整企业净利润。

## 四、窗口与版本

业务区间统一明确起点包含、终点不含；采用北京时间。知识截止决定当时可见的事件，补齐数据后复算保留新旧结果和各自截止。

净收款先分别汇总成功支付和成功退款，再按业务对象关联，避免支付与退款明细互相乘行。折扣已经体现在成交净额中时，不再重复扣减。

## 五、差异留档

交付对账应包含两侧原结果、公式与范围、已解释项、未解释项及来源。已解释项加未解释项应等于总差。发现源记录问题时，记录修复建议，不能为消除差额直接改写事实。

来源依据：收入、成本、费用、支付退款的数据定义及公开对账口径。本档为课程合成企业经营资料，不替代法定总账或现实财务制度；报告留档程序为模拟业务规程。
