# 会员身份关联与活动名单处理规范

行野运动集团 · 会员运营部 / 数据运营组

文件号：XY-CRM-R001；版本：1.0。制度依据：《会员识别规则》，原件发布于 2023-01-01 21:00。适用范围：活动名单整理、渠道身份与会员关联、历史订单分析。

## 一、身份对象

渠道身份与会员档案分别登记。一个外部标识须连同渠道确定含义，不能跨平台仅凭相同字符串判定为同一个人。姓名相似或地址相近不构成已经验证的会员关联。

身份关联记录保留绑定确认时间和系统可知时间。跨渠道覆盖并不完整；未匹配对象保留未知身份，不能强行归并到相似会员。

## 二、历史订单

历史订单保存下单时已知的会员快照。后来完成绑定的渠道身份，不回填到当时会员为空的订单，以免把未来身份信息带入历史分群。

分析“当时已知会员”时，仅使用截止前可见的关联，并尊重订单原快照。需要按当前身份重新观察旧记录时，应另列为新口径，明确与历史会员口径不同，不覆盖原结果。

## 三、活动名单整理

导入名单保留原文件、原行号、渠道标识和原始值。先检查编码格式、缺失、重复及渠道含义，再给出候选关联；规范化前后的值和处理理由保留。

重复记录、无法匹配、格式不合法和缺少关键字段分别计数。格式清理不自动授权删除业务对象；影响结论的删行或身份归并须形成明确处理决定，并保存变更前后行数。

## 四、关联结果核对

清洗结果至少保留成功匹配、仍未匹配及被排除原因，核对输入输出行数与金额是否守恒。将名单关联订单时先检查关联键唯一性，防止一对多关系重复计算订单金额。

匹配率只描述当前名单、当前规则和截止下的覆盖。未匹配不能等同没有购买，匹配成功也不保证能识别该顾客在全部平台的消费。

## 五、访问与留档

导出和共享名单遵守原租户、区域及字段权限，不在业务说明中附真实个人信息。来源依据：会员识别原件、渠道身份及绑定定义、订单快照口径。本档为课程合成企业资料；文件清洗与决定留档步骤为模拟业务规程。
