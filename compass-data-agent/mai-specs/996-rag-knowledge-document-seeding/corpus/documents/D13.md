# 经营数据源覆盖与报告就绪说明

行野运动集团 · 数据运营组 / 经营分析组

文件号：XY-DATA-R001；版本：1.0。整理日期：2026-10-24。依据现行数据字典和源侧完整度定义整理；原制度签发时间未载明，本文作为口径参考使用。

## 一、来源与覆盖

订单管理提供订单及支付相关经营事实，仓储提供库存和履约过程，门店系统提供门店业务。平台渠道通过商品日表和活动报告提供汇总数据；自有渠道另有浏览、曝光及会员关联资料。

天猫、京东、抖音的商品访客汇总不等同自有渠道逐人行为明细。报告缺少用户级轨迹时，不能推演成完整跨平台顾客路径。

## 二、采集状态与资产就绪

源水位用于说明某来源的采集状态。具体报表能否出数，还要检查对应资产、业务期间和知识截止下的完整度声明。一个来源显示恢复，不能推定所有资产已经齐备。

资产状态分为 PENDING、PARTIAL、COMPLETE：PENDING 表示该期报告尚未收到；PARTIAL 表示仍有缺口或对账未完成；COMPLETE 表示该业务期覆盖已经闭合且完成核对。选用状态时，取知识截止之前实际可见的最新声明。

## 三、零值、未知与空集合

确有覆盖且指标为零，才表示已知零值。报告未收到、归因覆盖未知、观察窗未成熟、无权读取和筛选后没有对象，分别标注，不能统一填零。

平台商品报告版本更新时，应按业务粒度选择在截止前可见的版本，不将多个版本相加。订单没有发生与订单源尚未到齐，需要由来源完整度区分。

## 四、出报和修订

周期报告先核对目标期间各必需来源的就绪状态。关键来源未齐时，保留等待或部分数据说明；允许提供局部结果时，明确已覆盖范围，不用上期数据冒充本期。

回补后保持相同业务窗口，另记录新的知识截止和报告版本。保留旧结果、补齐通知及差异解释，不静默覆盖已发出的报告。

## 五、责任与留档

数据运营负责记录来源、业务期、状态及更新依据；经营分析负责保留使用的版本和截止。本文不设未经来源确认的统一到齐时刻或服务承诺。

来源依据：源水位、资产业务期完整度、平台报告和身份字段定义。本档为课程合成企业资料；出报与留档次序为模拟业务规程，实际状态须查询当期记录。
