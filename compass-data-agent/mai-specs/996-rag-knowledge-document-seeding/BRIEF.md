## 一句话描述

结合 998 合成经营事实与 DataAgent 用户故事，生产可追溯、按版本和时效检索的正式业务文档及向量库导入数据包。

## 背景

998 已交付交易、商品、库存、营销、售后和经营诊断数据，但现有业务文档主要是简短场景说明，尚不足以支撑不同岗位检索正式经营依据。用户希望补齐政策、口径、档案、批准计划及正式变更记录，并明确区分当前有效版本、历史依据、计划与执行事实。

本需求以 998 已发布数据为事实基线，关联 999 的 S01–S12 分析故事，定义文档生产、证据用途、版本与有效期、实体关联、原句溯源及可接入交付。PRD 已按独立子 Agent 评审更新；用户随后授权直接生产，现已完成 23 篇正文及配套引用数据，Phase 进入 review。创建依据见 [需求输入记录](context/requirements-intake.md)，当前有效需求与验收统一维护在 [PRD](spec/PRD.md)。

## 关键决策

- 首批固定为 D01–D23 共 23 篇、23 份首版正文，其中 7 篇扩写、16 篇新编；覆盖 12 类文档家族，逐篇用途、来源和分析故事以 PRD 为准。
- 主包仅面向行野运动集团 tenant 101，绑定 998 当前 diagnostic；不额外生产其他租户、demo 故障或历史规则正文。预测计划缺口与支付样本不足保留为分析限制。
- 发布正文不可变，保留历史版本、有效期与可知的替代 / 撤销记录；计划、事件和规则分别表达。
- 引用须定位原句、文档版本、章节 / 段落及原始来源；数据库派生文档登记同源关系，不能重复计为独立佐证。
- 交付冻结原文、机器目录、引用与来源映射、说明及独立内容验证材料，可附 JSONL 片段。内容验收通过即可完成本阶段交付；真实向量导入、召回和在线权限在后续接入阶段另验。
- 998 保持既有事实与原材料，999 继续维护生产 RAG 接入与平台权限。本轮已完成语料生产和离线检查，未执行真实向量导入或完整 Agent 分析。
- 用户明确同意直接生成，省略独立技术设计文档；采用人工编写并冻结正文、标准库脚本核验和导出的最小实现。省略阶段不记为技术评审已通过。
