## 已修复的关键发现

- 部分支付后取消可能按订单应付额退款、渠道日报遗漏部分支付现金：改为实际已收现金上限与累计单件分摊；新增 4,500 分部分支付/全额退回金标，实库报表守恒通过。
- 源批次按父证据时间移动，导致业务窗口错位和水位计数失真：保留原事件批次，让 available_at 等待父证据；新增边界测试、实际批次窗口与水位数检查，全量通过。
- 对账旧快照混用未来现金，迟到桥接项缺少实际样本：改为固定 9 月 29 日观察，业务截止与源迟到分列；独立 SQL 与私有五项桥接逐分一致，四个主要差异均非零。
- 留存参考查询缺少零活跃与未成熟单元，注释中的退款规则未与查询对齐：显式生成 0–12 月龄、区分不足/未成熟/成熟，采用交付购买事件口径；真实账号全量执行并验证边界。
- 大事务全量装载发生后端退出：采用候选库内逐块校验提交，始终保留约束与未发布状态；后续完整实库装载成功。异常根因仍未确定，不能据此推广吞吐结论。

## 语义版本复评

范围：TECH_DESIGN §10、用户确认的同库 `retail_v2` 隔离重建。保留旧库与旧活动清单，审查冻结素材、条件生成、时点语义、模型失败边界、物理 schema 映射和课程分析 SQL。仍为实施者自审，独立 SQL、真实角色登录及固定金标提供不同计算路径的证据。

已修复的重要发现：

1. P1，商品语义：通用 BALL 规格使足球出现 6/7 号，PACK 将整筒网球重量当单球，城市包和驮包套用通用容量。已在新冻结字典中明确品种/产品规格、单位重量和整包计算，保留父版本；增补负例与落库门禁。网球每只 58 克对照 ITF 2026 Appendix I，其他课程参数不作为行业统计或比赛认证。
2. P1，可观测时点：支付事故材料原统一标注当天 09:00 发布，正文描述了稍后的恢复。现改为当日晚间发布，另加入截止时刻明确、从收入分录与商品档案生成的两份材料；月收入按北京时间切窗，并用独立 SQL 核对材料数字。
3. P1，场景验收：原 S05 仅验证存在缺货/退货。现检查指定跑鞋黑色 42 码、同款其他规格在同地点当时有货，以及后续交付恢复；fixture 保留最小边界豁免，dev/demo 要求后续交付。
4. P1，观察性队列：原 S09 校验按连续会员编号定位，无法随语义客户重新分配。已改为读取实际队列 ID，时间、分母和前趋势反例保持独立核对。
5. P2，模型错误处理：供应商返回合法 JSON 数组或错误 envelope 时曾绕过修复日志。现按错误响应记录并计入最多三次尝试，预算不退回；新增模拟服务回归测试。

当前证据：39 项单元/实库测试通过，含新 schema 隔离和 57 项角色检查；`pnpm check` 10/10 任务通过，根 `npm test` 通过。新增课程 SQL 已在开发库执行。最终两次 100,000 单离线重放、三个 seed 的修订后结果、全量新 schema 验证和旧表逐表指纹核对仍在执行，完成前不作无条件合并结论。
